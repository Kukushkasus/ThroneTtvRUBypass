# Bypass RussiaTtv — профиль маршрутизации для Throne

Готовый профиль маршрутизации для VPN-клиента **[Throne](https://github.com/throneproj/Throne)**
(бывший Nekoray), который решает конкретную проблему: Twitch в России
периодически режется/тормозит по DPI, а гонять **весь** трафик через VPN
не хочется — это медленнее и не нужно для остальных сайтов.

Этот профиль настраивает так:

- **Twitch** (`twitch.tv`, `ttvnw.net`, `jtvnw.net`, `twitchcdn.net`) —
  всегда идёт напрямую, в обход VPN
- Все российские сайты/сервисы (по спискам `geoip-ru`, `geosite-ru` и т.п.) —
  тоже напрямую
- Всё остальное (не-российское, не-Twitch) — через прокси/VPN, как обычно
- DNS-запросы перехватываются (`hijack-dns`), чтобы резолвинг доменов
  работал корректно с учётом правил выше

То есть VPN включён постоянно, но нагружает его только не-российский и
не-Twitch трафик — сам Twitch и российские сайты идут напрямую и быстро.

## Как использовать

1. Установи и настрой [Throne](https://github.com/throneproj/Throne)
   с любым рабочим VPN/proxy-конфигом (outbound `proxy`)
2. Скопируй содержимое файла [`bypass-russia-twitch.txt`](./bypass-russia-twitch.txt) —
   это ссылка вида `throne://route/...`
3. В Throne: **Profiles → Import from clipboard/URL** — вставь скопированную
   ссылку
4. Выбери этот профиль маршрутизации активным

## Как это устроено технически

Файл — это URL-схема `throne://route/<base64>`, где в base64 закодирован
JSON с правилами маршрутизации (`throne-route-profile`). Можно раскодировать
и посмотреть/поменять руками:

```bash
python3 -c "
import base64, json
s = open('bypass-russia-twitch.txt').read().strip().split('throne://route/')[1]
s += '=' * (-len(s) % 4)
print(json.dumps(json.loads(base64.urlsafe_b64decode(s)), indent=2, ensure_ascii=False))
"
```

Чтобы добавить ещё один сайт в прямой обход VPN — по аналогии с правилом
`"twitch direct"` добавь свой блок с `domain_suffix`, закодируй JSON обратно
в base64 (url-safe, без padding) и получишь новую ссылку `throne://route/...`.

## Дисклеймер

Профиль просто указывает, какой трафик идёт напрямую, а какой — через уже
настроенный тобой VPN/прокси. Сам VPN-конфиг сюда не входит — это только
маршрутизация поверх твоего существующего подключения.
