# Bypass RussiaTtv

Профиль маршрутов для Throne (бывший Nekoray). Нужен для того, чтобы Twitch нормально работал в России, но при этом не гонять через VPN вообще всё подряд.

## Что делает

- Twitch (twitch.tv, ttvnw.net, jtvnw.net, twitchcdn.net) идёт напрямую, без VPN
- Российские сайты тоже идут напрямую
- Всё остальное как обычно летит через VPN/прокси

В итоге VPN не простаивает без дела на Twitch и на русских сайтах, а работает только там, где реально нужен.

## Как поставить

1. Установи Throne и настрой в нём любой рабочий VPN/прокси
2. Открой файл `Bypass russia twitch`, скопируй оттуда ссылку (она начинается с `throne://route/`)
3. В Throne: Profiles → Import from clipboard/URL, вставь ссылку
4. Включи этот профиль

## Если хочешь добавить свой сайт в обход

Ссылка это просто закодированный в base64 JSON. Раскодировать можно так:

```bash
python3 -c "
import base64, json
s = open('bypass-russia-twitch.txt').read().strip().split('throne://route/')[1]
s += '=' * (-len(s) % 4)
print(json.dumps(json.loads(base64.urlsafe_b64decode(s)), indent=2, ensure_ascii=False))
"
```

Внутри увидишь блок с доменами твича, скопируй его, поменяй домены на свои, а потом закодируй JSON обратно в base64 (обязательно url-safe и без = в конце).

## Важно

Тут только правила маршрутизации. Сам VPN/прокси профиль сюда не входит, его надо настроить отдельно в Throne.
